# 系统使用指南

## 角色说明
系统包含三种角色：学生、辅导员、院长。学生负责提交各类申请并维护个人档案；辅导员负责审核名下学生的申请、管理学生数据；院长查看全局统计看板。

## 学生端功能
- 主面板：查看创新创业学分、社会实践学分的完成情况与距毕业要求差额，接收驳回提醒。
- 社会实践：提交社会实践活动与志愿服务记录，支持修改、删除待审核或被驳回的记录。
- 创新创业：涵盖前沿学术报告、年度创新创业项目、科技创新竞赛、创业实践、学术论文、申请专利、其他实践活动七类申请。
- 个人荣誉 / 技能证书 / 组织经历 / 入党情况：提交与维护相应记录。
- 综合素质成绩：查看各学期 GPA、综测成绩与专业排名。
- 成长档案：预览个人信息、教育经历、荣誉、证书、实践、双创等全部记录，一键导出 PDF 或 Excel。
- AI 助手：右下角抽屉对话，可咨询学分规则、查询个人学分与记录进度。

## 提交申请注意事项
- 标注星号的字段为必填项。
- 佐证材料支持 jpg、png、pdf 格式，单个文件不超过 10MB。
- 创新创业类申请的学分由选择的认定项自动计算，无需手填。
- 提交后请关注审核状态，被驳回的记录会给出驳回原因，修改后可重新提交。

## 辅导员端功能
- 主面板：查看各模块待审核数量汇总，点击可直达对应审核列表。
- 审核中心：按模块切换审核列表，可调用 AI 审核建议辅助决策，执行通过或驳回操作。
- 学生管理：查看名下学生列表与学分完成情况，支持单个新增、批量导入、修改与删除学生。

## 院长端功能
- 主面板：查看全校学生规模、待审核总量、各学院学生分布、双创学分分布与平均 GPA 趋势。

## 常见问题
- 忘记密码请联系辅导员重置为初始密码 123456。
- 材料上传失败请检查文件格式与大小。
- 学分计算口径以《创新创业与社会实践学分认定办法》为准，可在 AI 助手中直接提问。
